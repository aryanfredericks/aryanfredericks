### 👨‍💻 About me

I build practical, scalable AI systems end to end — from data ingestion and embedding, through LLM orchestration, to a deployed API with reproducible MLOps.

- 🔭 **Currently building** multi-agent systems with **LangGraph** and hybrid **RAG** pipelines
- 🌱 **Currently learning** evaluation of LLM outputs, vector search at scale, and agent design patterns
- 🎓 **Studying** M.Sc. Robotics & Artificial Intelligence at the **University of Glasgow**
- 💬 **Ask me about** LLM systems, RAG, agentic AI, FastAPI, and MLOps (MLflow · DVC · CI/CD)
- 📫 **Reach me at** aryanfredericks21@gmail.com
- ⚡ **Fun fact** I think a system you can't measure is a system you can't trust — so I build the eval suite first
